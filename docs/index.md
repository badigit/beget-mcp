# beget-mcp — MCP-сервер для хостинга Beget

Управление сервисами [Beget](https://beget.com/p1211871) из AI-агентов по
[Model Context Protocol](https://modelcontextprotocol.io/): 73 инструмента,
полное покрытие [Beget REST API](https://beget.com/p1211871/kb/api/).

Исходники и установка — [github.com/badigit/beget-mcp](https://github.com/badigit/beget-mcp).

## Установка

```bash
pip install -e .

claude mcp add beget -s user \
  -e BEGET_API_LOGIN=your_login \
  -e BEGET_API_PASSWORD=your_password \
  -- python -m mcp_beget
```

## Чем отличается от голого API

Beget `dns/changeRecords` заменяет зону целиком: запись одного типа стирает все
остальные. Инструменты DNS делают read-merge-write и отказываются писать, если
зону не удалось прочитать. Ошибка метода у Beget приезжает внутри
success-конверта (HTTP 200, `status: success`, `answer.status: error`) — клиент
это распознаёт и райзит, иначе `except` никогда не срабатывает, а зона
затирается молча.
